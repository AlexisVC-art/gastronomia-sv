
# 🇸🇻 Sabores SV — Gastronomía de El Salvador

Landing Page moderna y responsive enfocada en la gastronomía típica salvadoreña, desarrollada con HTML5, CSS y JavaScript.

---

# 📌 Descripción del Proyecto

Este proyecto consiste en una Single Page Application (SPA) inspirada en la cultura culinaria de El Salvador.

La página incluye:

- Restaurante y pupusería tradicional
- Tours gastronómicos
- Eventos y banquetes
- Formulario interactivo de reservas
- Diseño responsive adaptable a móvil y escritorio

El objetivo principal es promover la gastronomía salvadoreña mediante una experiencia visual moderna y atractiva. (es por la nota, obvio)


# 🛠 Tecnologías Utilizadas

- HTML5 Semántico
- CSS Moderno
- JavaScript Vanilla
- CSS Grid
- Responsive Design

# ✨ Funcionalidades

## ✅ Navbar Responsive
- Menú hamburguesa funcional en dispositivos móviles
- Navegación suave entre secciones

## ✅ Hero Section
- Imagen de fondo fullscreen

## ✅ Sección Nosotros
